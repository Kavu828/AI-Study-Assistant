# 📚 AI Study Assistant

## 🚀 Overview

AI Study Assistant is an AI-powered web application that helps students generate study notes and quizzes from uploaded images and PDF documents. The application uses Google's Gemini AI to analyze the uploaded content and create structured notes along with multiple-choice quizzes for self-assessment.

---

## ✨ Features

- 📂 Upload Images and PDF files
- 🤖 AI-Generated Study Notes
- 📝 AI-Generated Multiple Choice Quizzes
- ✅ Instant Quiz Evaluation
- 🎯 Score Calculation
- 📊 Accuracy Percentage
- 🌟 Performance Feedback
- 🔄 Retake Quiz
- 📁 Upload Another File

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Kavu828/AI-Study-Assistant.git
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
